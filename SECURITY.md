# Security Policy of @kaito-tokyo/LDTX

While we make best efforts to address vulnerabilities, this project is provided AS IS without any warranty. We do not guarantee security updates or support, although we strongly advise you to stay on our latest version to avoid any issues.

## Reporting a Vulnerability

If you find any security vulnerabilities, please report them to us privately. Do not disclose vulnerabilities to any third party. We are responsible for resolving issues with our products.

- [GitHub Security Advisories](https://github.com/kaito-tokyo/LDTX/security/advisories)
- [Security Team of Kaito.tokyo](mailto:security@kaito.tokyo)
- `#security` channel of kaito.tokyo Slack workspace (internal member only)
